# Flight Delay Analysis Dashboard

## Project Overview
This project analyzes flight operations to understand flight delays, cancellations, monthly flight trends, and delay categories using Power BI.

## Tools Used
- Power BI
- Data Visualization
- Data Analysis

## Dashboard Features
- Total Flights
- Delayed Flights
- Cancelled Flights
- Flight Delay Percentage
- Monthly Flight Trends
- Flight Status Analysis
- Delay Category Analysis

## Key Objectives
- Analyze flight delays and cancellations.
- Identify monthly flight trends.
- Understand different delay categories.
- Present flight performance insights through interactive visualizations.

- Power BI dashboard development
- Data visualization
- KPI reporting
- Business data analysis
